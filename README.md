# Line Editor

A simple C-based line editor that lets you:

- insert lines
- delete lines
- display the document
- save to a file
- load from a file
- search text
- replace text
- undo the last change

## Features

- Command-line interface
- Works in C using arrays
- Lightweight and beginner-friendly

## How to compile

```bash
gcc -Wall -Wextra -std=c11 line.c -o line
```
